# 0.5.84: resolution of the director requirements, items 1–4 (2026-10-16)

Classes: **Resolved** means implemented and tested within the stated scope, with no known gap there. **Partial** means implemented and tested for the listed scenarios, with the gaps listed. **Residual** means known and not addressed in 0.5.84. **Proposal** means it needs a maintainer decision.

All evidence comes from local tests on one machine. That includes multi-process tests over loopback with scripted faults and a scripted adversary, plus bounded model checking. None of it is a claim about how a distributed network run by independent operators behaves.

Constraints kept:
- No native token.
- Fees stay at 0.1 % and 3 %.
- Protocol time comes from block height.
- Poseidon is unchanged.
- No new runtime dependency.
- Test keys are created in memory or in temporary directories only. **No persistent private key was generated or committed.**

| 1 | Economic state, commit journal and BFT state in one atomic unit: WAL, fsync, atomic rename, checksums | Resolved (lab) | `src/node/unified-state-store.ts`.
